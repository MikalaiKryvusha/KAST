## Постановка, вставленная владельцем

Исследуй Artemis Android fork и moonlight-common-c. Найди все места, где временная потеря UDP/TCP/network connectivity приводит к connectionTerminated, ML_ERROR_*, Error Code -1, остановке Activity или окончательному завершению stream session.

Цель: при временной потере сети до 60 секунд НЕ завершать игровую сессию. Сохранять последний декодированный видеокадр, при восстановлении network connectivity выполнять корректное восстановление streaming connection без возврата пользователя на список хостов.

Не ухудшать обычное поведение при настоящем завершении сессии сервером. Добавить configurable reconnect grace period, default 60 seconds. Добавить подробное логирование причины disconnect/reconnect.
