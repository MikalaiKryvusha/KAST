## Боль

Владелец играл через Artemide (`derflacco/moonlight-android`). В Artemis, на котором построен KAST, нет 31
коммита Artemide о плавности и задержке. Кроме того, в интернете есть целые треды о том, как выжать всю
производительность из разных чипов MediaTek Dimensity и Qualcomm Snapdragon (слова владельца).

**Чем проверим, что сработало:** в настройках KAST есть отдельное экспериментальное меню; каждая оптимизация
включается в нём своим переключателем; на телефоне владельца включённая оптимизация даёт измеримый выигрыш по
счётчикам оверлея производительности (задержка декодера, пропуски кадров) в одной и той же игре и сети — замер до и
после.

## Постановка (слова владельца, опечатки исправлены)

Да (переносить оптимизации Artemide). В интернете есть целые треды о том, как выжать все соки из разных чипов
MediaTek Dimensity и из разных чипов Snapdragon. Нужно отдельное экспериментальное меню в настройках с включением
этих оптимизаций.

## Источники оптимизаций

**1. Artemide сверх Artemis** (сверка GitHub 2026-09-26: ahead 31 / behind 76):

- привязка «горячих» потоков к большим ядрам процессора, расширенное определение кластеров;
- аудиопоток с наивысшим приоритетом реального времени;
- «Snappy Input» (две ревизии);
- мягкий слив очереди в режиме Low-latency + CAP_FPS; уменьшение колебаний частоты;
- AV1 на MediaTek: RFI через vendor keys и AdaptivePlayback; low-latency после старта кодека;
- LFR — режим темпа кадров (описан в README Artemide).

**2. Треды сообщества по чипам MediaTek Dimensity и Snapdragon** — ещё не собраны. Первый шаг работы по идее —
разведка `researches/02_*`: найти треды, выписать каждую оптимизацию с источником, чипом и заявленным эффектом;
код — только по этому документу (`AGENT_GUIDE.md` → «Recon before code»).

## Как устроено

- Отдельное экспериментальное меню в настройках KAST.
- Каждая оптимизация — свой переключатель; по умолчанию выключен.
- Каждый переключатель получает кнопку [i] с пояснением (`ideas/06_settings_info_buttons.md`) и тексты на EN и RU
  (`ideas/03_localization_en_ru.md`).
- Оптимизации переносятся по одной, каждая — с замером до и после на телефоне владельца.
