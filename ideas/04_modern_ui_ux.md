## Подход (слово владельца 2026-09-26)

- **Сохраняем то, что есть, и делаем лучше:** экраны, их состав и привычные пути пользователя остаются.
- **80 % улучшения за 20 % усилий:** первыми идут правки с наибольшим видимым эффектом при малой цене.
- **Ищем в интернете свежее:** новые версии SDK и библиотек интерфейса, современные подходы, палитры, радиусы
  скруглений.
- **Никакого Liquid Glass:** стеклянные полупрозрачные поверхности с размытием (язык оформления Apple) в KAST не
  идут.

Первый шаг работы по идее — разведка `researches/03_*`: свежие версии SDK и библиотек интерфейса Android,
современные подходы, палитры и радиусы, каждое — с источником и ценой переноса на нынешний код; код — по этому
документу. Порядок экранов агент выбирает по правилу 80/20: первыми — экраны, которые пользователь видит чаще всего.
