## KARTUN 1.0.1

- **FreeDroidWarn.** On the first launch of a new version KARTUN shows one dialog about Google's planned developer verification for Android apps (2026/2027) and what you can do about it ([Keep Android Open](https://keepandroidopen.org)). Tap OK and it stays quiet until the next version.
- **Install and update with [Obtainium](https://github.com/ImranR98/Obtainium)** — the button in the README adds KARTUN in one tap. The version string is now plain `1.0.1`, the same as the release tag, so Obtainium sees updates.

Installs on top of KARTUN 1.0 (same signing key), your models and settings stay.
