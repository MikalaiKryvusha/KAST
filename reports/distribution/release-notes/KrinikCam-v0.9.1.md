## KrinikCam 0.9.1

> **Reinstall once.** The 0.9 APK on GitHub was signed by the build robot's temporary key. From 0.9.1 on, every release is signed with KrinikCam's own permanent key, so Android cannot update 0.9 in place: uninstall 0.9 and install 0.9.1. Later updates go on top as usual.

- **FreeDroidWarn.** On the first launch of a new version KrinikCam shows one dialog about Google's planned developer verification for Android apps (2026/2027) and what you can do about it ([Keep Android Open](https://keepandroidopen.org)). Tap OK and it stays quiet until the next version.
- **Install and update with [Obtainium](https://github.com/ImranR98/Obtainium)** — the button in the README adds KrinikCam in one tap.
