## 5. Found

- The option dialog showed `60с` (no space; the seekbar adds a space only to suffixes longer than one character). Fixed:
  a one-letter unit gets a no-break space (`SeekBarPreference`); run 9 shows «60 с».
- The outage label stayed frozen behind the end dialog after a termination during silence (run 5 screenshot, found by the
  judge). Fixed in `Game.connectionTerminated`; run 7 confirms. Also fixed on the way: after a hold the «poor connection»
  text the label had covered is given back.
- **Open risk, not addressed in F2 (decision `[AI]`, deferred to F3):** input sent during the silence is reliable ENet
  traffic and arrives at the host as a burst after the network returns (now up to the wait, 300 s max; before F2 — up to
  10 s). Not observed in the runs (nobody touched the screen during a loss). F3 plan 06 blocks input while there is no
  connection; F2 leaves it open on purpose, recorded in plan 04 → risks.
- Leftover Artemis branding seen on the way (not F2): settings «Язык — Язык, который будет использоваться в Artemis»;
  goes to idea 03/07 (texts and names).
- Precision: K4 «≈0.13 s» uses the 0.99 s clock offset of runs 3 and 5; with the F1 offset (1.064 s ± 0.17 s) it is
  0.13–0.20 s — the ≤ 2 s target holds either way. Run 1's `offset.txt` is unreadable (a locale bug of the first
  droprun, fixed before run 3).
