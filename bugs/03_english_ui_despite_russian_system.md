## Symptom
Владелец видит английский текст при русском языке системы.

## Forensics
- Язык планшета: `getprop persist.sys.locale` → `ru-BY`; языки приложения не заданы (`cmd locale get-app-locales
  com.limelight.kastdebug` → `[]`).
- Экран списка хостов KAST показан по-русски («Поиск хост-ПК в вашей локальной сети…», «Добавление ПК вручную»,
  «Сопряжение»).
- Экран приложений хоста: надписи DESKTOP, RESUME, TERMINATE, REMOTE INPUT, REMOTE MONITOR — внутри картинок-обложек (баг 02).
- Перевод Artemis на русский неполный (`ideas/03`: у большинства языков 20–40 % строк) — недостающие строки Android берёт
  из английских по умолчанию.

## Root cause / Hypotheses
1. На экране приложений английский — это картинки сервера и клиента (баг 02), а не строки интерфейса.
2. На других экранах (настройки, диалоги) — непереведённые строки `values-ru/strings.xml`.

## Fix plan
Пройти все экраны KAST UI-агентом (`labels`), собрать список английских строк при русской системе — это перечень работы
для `ideas/03`; надписи плиток — по багу 02.
