## Symptom
На экране приложений хоста у плиток разный размер надписей: DESKTOP крупным узким шрифтом, RESUME и TERMINATE мельче,
REMOTE INPUT и REMOTE MONITOR ещё иначе (снимок экрана Титана 2026-09-26 13:15).

## Forensics
- Список приложений сервера (API админки Vibepollo, 2026-09-26): `Desktop` → `desktop.png`, `Remote Input` →
  `remote-session/remote-input.png`, `Remote Monitor` → `remote-session/remote-monitor.png`. Надписи на этих плитках —
  часть картинок-обложек, которые отдаёт сервер; KAST рисует картинку, а не текст.
- Плитки RESUME и TERMINATE сервер не отдаёт как приложения — их, по всей видимости, рисует сам клиент (проверить в коде
  `AppView`/адаптера).

## Root cause / Hypotheses
1. Надписи с разным шрифтом «зашиты» в разные картинки: обложки сервера и собственные картинки клиента сделаны в разном стиле.
2. Если владелец имел в виду другой экран — нужен снимок или название экрана (вопрос владельцу).

## Fix plan
Показать владельцу снимок с разбором (что из сервера, что из клиента) и предложить вариант: единый стиль плиток в KAST —
подпись текстом поверх картинки одним шрифтом, а не текст внутри картинок. Решение по виду — владельца (идея 04).
