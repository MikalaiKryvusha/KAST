**Fixing:** по решению владельца (раздел ниже) — модальный диалог вместо письма

- Ситуация. KAST на Титане, журнал производительности включён и в нём есть запись, «Настройки» → «Поделиться логами
  производительности».
- Действие. Пользователь нажимает пункт, затем по очереди «Поделиться», «Сохранить файл» и ссылку в тексте.
- Результат. Открывается диалог «Журнал производительности» с адресом issues KAST. «Поделиться» открывает стандартный
  выбор Android с одним файлом без адресата. «Сохранить файл» открывает системное «Сохранить как», после сохранения
  всплывает «Журнал сохранён». Ссылка открывает issues KAST.
- Проверка. `git grep -n -i "artemistics" -- app/src/main` пусто. Сохранённый файл совпадает с журналом. Снимки
  показаны владельцу на Windows.

## Symptom
`app/src/main/res/values/strings.xml`: `email_recipient` = `artemistics.logs@gmail.com`;
`StreamSettings.java:786` (`share_performance_logs`) собирает журнал `PerformanceDataTracker`, пишет его в
`artemistics_logs.txt` и открывает почтовый клиент с этим адресом. Рядом в `res/xml/preferences.xml:938` — ссылка на вики
Artemis «Performance-Statistics-Collection».

## Root cause
Наследство форка: Artemis собирает статистику производительности своих пользователей на свою почту. В KAST это значит, что
журналы KAST попадут в статистику Artemis — то, о чём автор Moonlight просит форки не делать (комментарий в `app/build.gradle`).

## Fix plan — по решению владельца (раздел ниже)
1. Нажатие на «Поделиться логами производительности» (журнал есть) → модальный диалог KAST: заголовок, короткий текст
   «куда и как» (адрес `github.com/MikalaiKryvusha/KAST/issues` — ссылкой; «сохраните журнал файлом или поделитесь им и
   приложите файл к тикету»), кнопки «Сохранить файл», «Поделиться», «Закрыть».
2. «Сохранить файл» — системный диалог Android «Сохранить как» (`ACTION_CREATE_DOCUMENT`, имя
   `kast_performance_log_<дата-время>.txt`), запись в выбранное место; тост «Журнал сохранён».
3. «Поделиться» — стандартный выбор Android (`ACTION_SEND` + `createChooser`), файл через `FileProvider`, без адресата.
4. Адрес Artemis убран: `email_recipient`, `email_prefix_message`, `email_subject`, `email_chooser_title`,
   `toast_no_email_clients` — удалены из всех языков (больше не используются); файл в кеше — `kast_performance_log.txt`.
5. Новые строки — на всех языках (принцип `MASTER_PLAN.md`), проверка по ключу (EXP-0004).
6. Проверка на Титане: включить журнал производительности, сделать короткий стрим, открыть диалог (снимок — показать
   владельцу на Windows), «Поделиться» открывает системный выбор, «Сохранить файл» — системный диалог сохранения.

## Проверка на Титане (2026-09-26 16:04–16:05, сборка `nonRoot_gameDebug` ветки `moonlight-noir` с этой правкой)

- **Журнал.** Стрим на 25 с журнала не дал. Запись появляется, только если за время стрима была хотя бы одна
  секунда ровно с заданной частотой кадров (`MediaCodecDecoderRenderer.java:1883`, `targetFpsMatched`); неподвижный
  рабочий стол кадров почти не шлёт. Код записи журнала достался от Artemis, правка бага 04 его не трогает. Так как
  проверялся диалог, в настройки приложения через `run-as` была положена одна запись-образец в форме
  `PerformanceDataTracker` (в поле версии помечена `KAST test fixture`). После проверки образец удалён, флажки журнала
  и статистики выключены.
- **Диалог.** Заголовок «Журнал производительности»; текст с адресом `https://github.com/MikalaiKryvusha/KAST/issues`
  (подчёркнут); кнопки «СОХРАНИТЬ ФАЙЛ», «ЗАКРЫТЬ», «ПОДЕЛИТЬСЯ».
- **Поделиться.** Стандартный лист Android: «Поделиться 1 файлом — `kast_performance_log.txt`», адресата нет.
- **Сохранить файл.** Системное «Сохранить как» в «Скачанные» с именем `kast_performance_log_20260926-1604.txt`.
  После «Сохранить» всплыло «Журнал сохранён», на устройстве файл в 363 байта: ровно та запись. Тестовый файл удалён.
- **Ссылка.** Открывает приложение GitHub на «KAST → Issues».
- **Критерий.** `git grep -n -i "artemistics" -- app/src/main` пусто. Пять почтовых строк удалены из всех языков.
  Семь новых строк есть в 26 языковых файлах `strings.xml` и в основном `values/strings.xml`. Файлы `values-ckb` и
  `values-fa` пусты целиком, как и в Artemis: эти языки видят английский.
- **Снимки** (вне репозитория, на них уведомления владельца): `D:\Android\private\evidence\bug04\`. Лист из четырёх
  снимков открыт на Windows.

**За рамками бага.** Соседний пункт «Панель производительности» ведёт на вики Artemis
(`preferences.xml:938`, «Performance-Statistics-Collection»), и в его тексте сказано: «не поддерживаются Artemis».
Это ссылка на чтение, туда ничего не уходит. Оставить её или убрать, решится вместе с переименованием в идее 03.

## Decisions made without the owner
- Текст диалога и подписи кнопок на всех переведённых языках. Владельцу показан русский вариант на снимке, он принял.

  сообщение об ошибке вместо падения настроек (находка судьи). Эта ветка на Титане не проверялась: там экран есть.
- Файл сохраняется через системное «Сохранить как», а не молча в «Загрузки». Так пользователь сам выбирает место, и
  приложению не нужно разрешение на запись в память.
- Для проверки положена запись-образец в настройки. Код, который пишет журнал, достался от Artemis и не менялся.
